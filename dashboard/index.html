🌐 Distributed Systems Project

Integrated Demonstration of 5 Core Distributed Systems Concepts

Module 1: Socket Programming

Client–server communication using low-level TCP sockets for hostel complaint submission.

Module 2: Java RMI

Remote Method Invocation to retrieve hostel room and warden details from a remote object.

Module 3: RPC (REST API)

REST-based notice board system demonstrating stateless client–server interaction.

Module 4: Peer-to-Peer (P2P)

Decentralized resource sharing where each peer acts as both client and server without central storage.

Module 5: Shared Memory

Live mess feedback counter using shared memory and semaphores to prevent race conditions.
